# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it by sending an email to `security@example.com`.  Do not publicly disclose the vulnerability until a fix has been released.

## Sensitive information

Do **not** store secrets (such as API keys, tokens or passwords) in this repository.  Use GitHub secrets and OIDC authentication where possible.  Rotate credentials regularly and remove any secrets from the commit history if they are accidentally committed.
